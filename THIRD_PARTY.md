# Third-party resources

No third-party source code, model checkpoint, or dataset is vendored in this
repository.

## UrbanFloodCast

- Source: https://github.com/HydroPML/UrbanFloodCast
- Dataset: https://doi.org/10.5281/zenodo.15700880
- Article: https://doi.org/10.1016/j.jhydrol.2025.133705

The baseline adapter loads the upstream DNO, FNO3D, and U-Net3D classes from a
user-supplied checkout. The MIT license in this repository applies only to our
adapter and other original files; it does not grant rights to external code or
data. Users must review the terms published by each original provider.
